## ① 一句话定位 + 行业锚定

**「全量、可审计、能自证的 AI 质检中台」**——把传统 1–3% 人工抽检升级为 **100% 全量 AI 质检**，把"关键词命中"升级到"语义 + 意图 + 情绪"理解，覆盖对话 / 通话 / 客服三类合规质检，专为**消费金融客服合规**而生。

**行业刚需（mock 文案据此写实，不再上网搜）**：金融"双录"要求 **100% 覆盖** + 数据留存 **10 年**；金管总局《消费者权益保护监管评价办法》**2025-09 施行**——合规漏检直接挂钩监管评级。差异化灵魂 = **多-agent 质检流水线可视化** + **转写时间轴逐句标注（违规红 / 合规绿）**。

---

## ② 视觉签名 / point of view

**「精密审计感」——冷静、克制、合规专业。** 不是炫技仪表盘，是一台让监管和法务都信得过的"审计仪器"。

- **Accent**：克制的深钢蓝（audit blue `#2F6FED` 级别），仅用于"命中 / 通过 / 焦点态"；**违规 = 朱红 `#D6453C`**、**合规 = 苔绿 `#2E9E6B`**、**风险待定 = 琥珀 `#E0A03A``——三色构成全站语义底，一页一 accent 不破。
- **质感**：发丝线分隔、tabular 数字、留白克制、卡片低饱和；禁玻璃涂满、禁 AI 紫发光、禁霓虹。整体像"证据卷宗 + 示波器"，而非营销页。
- **主题**：Dark（Command Graphite，审计室夜间监看）为旗舰，Light（Studio Porcelain，合规报告白纸感）为汇报默认；两套同构一键切。
- **微表情**：违规高亮用细下划波纹 + 左侧 2px 红条，不闪不抖；评分卡命中项 draw-in 勾选；时间轴游标随音频播放平移（缓动非线性）。

## ⑤ 核心模块详述（职责 + 关键交互 + mock 数据轮廓 + ECharts 图表，≥7 真图表）

### 5.1 全量对话/通话列表
- **职责**：取代 1–3% 抽检，呈现 **100% 全量**质检结果，按风险分层。
- **交互**：DataTable（可排序 + 空态 + skeleton）；列 = 会话ID/坐席/业务线(提前清贷·注销合规·银行卡管理·S客户路由)/渠道(通话·在线·邮件·Bot)/总分/违规项数/情绪峰值/状态；筛选 chip + 风险色点；行点开进工作台。
- **mock 轮廓**：今日全量 **48,620** 条；高风险 **312**、待复核 **86**。
- **图表①**：风险分布**旭日图**（业务线→风险等级）。

### 5.2 质检工作台（旗舰，见 ⑥）
- **左**：转写时间轴逐句回放（说话人分离：坐席/客户双轨气泡 + 静默段 + 抢话标记）；**违规句红底**、**合规话术绿底**、风险句琥珀；点句联动右侧评分项 + 音频游标定位。
- **右**：质检评分卡逐项命中（合规项/服务项/主观项分组，命中勾绿、扣分项展开证据原句）。
- **顶**：多-agent 流水线状态条（采集→ASR+说话人分离→结构化→双引擎并行→汇总评分），各 agent 实时状态灯。
- **图表②**：情绪/静默/抢话**情感曲线**（双折线 + 静默色块 area，draw-in）。

### 5.3 质检评分卡配置器（规则编排器，复用风控同款）
- **职责**：让主管**拖拽**组合质检项，无需写代码出一张评分卡。
- **交互**：左规则库（合规必读项/禁语/承诺类/费率告知…）→ 中画布拖拽排序 + 权重滑杆 → 每项二选一引擎徽标：**「规则模板」**（关键词/正则）或 **「LLM 语义项」**（可填 prompt：如"是否完整告知年化利率与逾期后果"）；右实时预览扣分逻辑。
- **图表③**：评分项权重构成**堆叠条**（合规/服务/主观三段占比）。

### 5.4 多-agent 流水线编排 ★（Hans 方案灵魂）
- **职责**：把 Hans 真实方案产品化——**按质检规则拆分的多本地智能体并行，再汇总打分**，解决"单 agent 准确率瓶颈 + 云端 API 高成本"。
- **交互**：流程画布（复用 §5 Agent 流程画布）：录音采集 → ASR 转写 + 说话人分离 → 文本结构化（意图/实体/情绪/静默/抢话检测）→ **双引擎并行**（规则模板引擎 ‖ LLM 语义评分）→ 多本地子 agent（合规 agent / 禁语 agent / 费率告知 agent / 情绪安抚 agent，各跑本地模型）→ **汇总 agent** 出评分卡。节点点开看分工/准确率/本地 vs 云端成本对比卡。
- **mock 锚点**：合规项准确率 **100%**、客服 **99%**、电销 **96%**（Hans 真实战绩量级）；**本地推理较云端 API 月省 ~62% 成本**(mock)。
- **图表④**：各子 agent 准确率 **雷达图**；**图表⑤**：本地 vs 云端 API 成本对比**柱图**。

### 5.5 实时质检预警流
- **职责**：通话/对话进行中即时拦截违规（禁语、未告知、情绪激化）。
- **交互**：右栏实时流卡片瀑布（颜色编码 + 倒计时严重度）；点开跳转该会话工作台。坐席侧可弹"实时辅导"建议话术（对标 Cresta 实时辅导思路，纯 mock）。
- **图表⑥**：今日预警**时段热力图**（24h × 业务线）。

### 5.6 坐席绩效排行 + 雷达
- **职责**：坐席合规/服务画像，定向辅导。
- **交互**：排行 DataTable（合规分/服务分/申诉成功率/趋势 Sparkline）+ 选中坐席**五维雷达**（合规·共情·解决·规范·效率）。
- **图表⑦**：坐席能力**雷达图**（多坐席叠加对比）。

### 5.7 复核 / 申诉工作流
- **职责**：质检争议闭环，保证可申诉、可终裁、留痕。
- **交互**：泳道看板（待复核→复核中→申诉→终裁→归档）+ 申诉详情抽屉（原评分 vs 复核意见 diff + 证据原句引用 + 裁决按钮）。坐席发起申诉、主管复核、合规官终裁，权限分明。
- **图表⑧**：申诉处理**漏斗图**（发起→受理→改判→驳回）。

### 5.8 合规话术覆盖率仪表盘
- **职责**：双录刚需可视化——必读合规话术（年化利率告知/冷静期/个人信息授权/逾期后果…）**覆盖率是否 100%**。
- **交互**：每条必读项一行 = 覆盖率进度 + 缺漏会话钻取；红区即监管风险。
- **图表⑨**：合规话术覆盖率**水平条形 + 目标线**；**图表⑩**：双录覆盖率**仪表盘 gauge**（目标 100%）。

### 5.9 自定义报表与趋势
- **职责**：给主管/合规官出可导出的趋势报表。
- **交互**：维度拼装（业务线×渠道×时间）→ 预览 → 导出占位（PDF/Excel mock）。
- **图表⑪**：质检合格率 / 违规率**双轴趋势折线**（含渐变面积）。

> 共计 **11 个 ECharts 真图**（旭日/情感双折线/堆叠条/雷达×2/成本柱/热力/漏斗/条形/gauge/双轴趋势），全部走项目统一 ECharts theme（透明底·发丝线·tabular·圆角柱·渐变面积·draw-in），**禁假 div 进度条冒充图表**。

## ⑥ 旗舰演示页（最炸的一屏）

**「质检工作台」三栏联动**——这一屏要让人 5 秒看懂"AI 怎么逐句判合规"：

- **顶部窄条**：多-agent 流水线状态（采集 ✓ → ASR ✓ → 结构化 ✓ → 双引擎运行中 → 汇总），各节点状态灯 + 微动。
- **左栏（转写时间轴）**：双轨说话人气泡随播放游标平移；**违规句红底 + 左 2px 红条**、合规话术绿底、风险琥珀；静默段灰色块标"静默 8s"，抢话处叠角标。点任一句 → 右栏定位对应评分项 + 音频跳转。
- **右栏（评分卡）**：合规/服务/主观三组逐项，命中勾绿色 draw-in，扣分项可展开"证据原句 + 触发引擎（规则/LLM）+ 扣分"。底部总分环形（红/绿语义）。
- **下方**：情感曲线（情绪折线 + 静默/抢话标记）贯穿整通时长，与时间轴游标同步。

**演示爽点**：拖动音频游标，左栏句子高亮 + 右栏评分项 + 情感曲线游标三处同步联动——"逐句可解释的 100% 全量质检"一目了然。

## ⑦ 差异化 + 反 slop 要点

**差异化灵魂**：
1. **多-agent 质检流水线可视化** ★——Hans 真实"按规则拆分本地智能体 + 汇总"方案，市面 demo 多是黑盒打分，本 demo 把流水线、分工、本地 vs 云成本全摊开。
2. **转写时间轴逐句标注（违规红/合规绿）**——证据可追溯到每一句，对标 Observe.AI Auto-QA 100% 覆盖 + Decagon hallucination detector 的可解释性。
3. **行业对标暗线（mock 文案点到，不展开页面）**：Observe.AI（30B 联络中心模型，Auto-QA 100% 覆盖通话/聊天/邮件/bot）、CallMiner、Cresta（实时辅导）、循环智能（销售+客服质检）、智齿科技（400 万小时标注 · 转写准确率 >90%）、得助（金融双录质检）——作为"我们对标谁"的可信锚，不堆 logo 墙。

**反 AI-slop 红线（ship 前逐条过）**：无 AI 紫发光/霓虹；无玻璃涂满；数字全 tabular-nums；用真实消金质检术语（双录/年化利率告知/冷静期/禁语/抢话/静默）无 lorem ipsum；UI chrome 无 emoji（用 lucide：ShieldCheck/Waveform/GitBranch/AlertTriangle/Gavel）；文案具体专业，禁"赋能/无缝/一站式"；一页一 accent；4px 网格；尊重 prefers-reduced-motion。

## ⑧ 5 分钟演示流

1. **0:30** 登录为「质检主管」→ 看板：今日全量 48,620 条、高风险 312、双录覆盖率 gauge。一句话："传统抽检 1–3%，我们 100% 全量。"
2. **1:30** 进**质检工作台**：播放一通"未告知年化利率"通话 → 左栏违规句红底高亮 + 右栏评分卡自动定位扣分项 + 情感曲线显示客户情绪激化。三栏联动是高光。
3. **2:30** 跳**多-agent 流水线编排** ★：讲 Hans 方案——按规则拆本地子 agent 并行 → 汇总；点成本对比柱图，"本地推理月省 ~62%，准确率合规项 100%"。
4. **3:30** 开**评分卡配置器**：拖一条新规则、切"LLM 语义项"、填一句 prompt → 实时预览扣分逻辑。证明可自定义、非黑盒。
5. **4:30** 切「合规官」身份 → 合规话术覆盖率仪表盘红区钻取 + 申诉工作流终裁一条 → 留存与审计页显示 10 年留痕。收尾："可解释、可申诉、可审计——监管要的三件套齐了。"
