> 工厂第二波 P1 · 矩阵综合分 22 · 视觉张力评级 **S（全矩阵最炸）**
> 设计契约见项目根 `DESIGN.md` 与 `00-总规划` §3，本文只补本 demo 的 point of view、模块与图表，不重复 token/字号/反 slop 通则。

## ① 一句话定位 + 行业锚定

**LLM 语音 agent 主动外呼的作战中枢**：从名单导入到拨号引擎、ASR 实时转写、对话引擎、TTS 情感语音、CRM 回写，全链路可视、可监控、可质检。
**行业锚定 = 消费金融**：信用卡激活回访 / 逾期催收提醒 / 理财产品回访 / 满意度回访四类场景。
**灵魂差异化 = 合规**：工信部累计处罚违规外呼企业 **>1500 家**（骚扰、数据泄露、线路违规），市面 **>40%** 产品存在参数虚标 / 高封号率 / 合规资质缺失——本 demo 把**合规频控、外呼资质、录音留痕**做成一等公民，定调"克制的合规回访"而非"狂轰滥炸电销"。

## ② 视觉签名 / Point of View

**「实时作战感 × 金融合规克制」。** 一句话：让人一打开就感到"这通电话此刻正由 AI 在打"，但绝不 spammy。

- **作战感**：旗舰监控墙用**实时跳动的坐席卡片墙 + 声波动画 + 流式转写**制造临场感；KPI 秒级 tick；接通瞬间卡片有脉冲。
- **合规克制**：默认主题 = Dark「Command Graphite」，accent 锁**翡翠绿**（合规/接通/正向，绿=放行的金融语义），**金**退为稀缺点缀（资质/认证徽章）；绝不用电销红包橙、不用霓虹紫发光。Light「Studio Porcelain」用于白班质检审计视角。
- **签名元素**：① 贯穿全站的**声波条**（接通中=翡翠流动波形，静音=灰平线，敏感词触发=琥珀脉冲）；② 转写流的**双气泡时间轴**（AI 翡翠 / 客户中性灰，带意图/情绪 chip）；③ 右上角常驻**合规状态灯**（频控余量 / 静默时段 / 资质有效期，三灯全绿才能发起活动）。
- 反"spammy 电销感"具体手段：无满屏红色急促感、无"立即抢购"式文案、所有话术示例都是**回访/提醒/确认**口吻；拨号节奏面板默认带"礼貌间隔/勿扰时段"约束可视化。

## ③ 角色 RBAC（4 角色 × 权限矩阵 + 登录页 + 角色切换，沿用 AuthContext）

| 角色 | 视角重心 | 关键权限 | 不可见/只读 |
|---|---|---|---|
| **外呼运营** (Campaign Ops) | 任务调度台 + 监控墙 | 建活动、导名单、起停外呼、调并发节奏 | 合规阈值锁定项只读；不可导出原始录音 |
| **话术设计师** (Script Designer) | 话术流编排器 + A/B | 编辑对话树/LLM 节点、配音色、发起 A/B | 不可操作线上活动并发；客户 PII 脱敏 |
| **合规/质检官** (Compliance & QA) | 合规质检中心 | 设频控/静默时段/敏感词、封停违规活动、调录音留痕、出审计报告 | 不可改话术业务逻辑（避免既裁判又运动员） |
| **业务主管** (Biz Lead) | 数据回流大盘 + 漏斗 | 看全量看板、转化漏斗、坐席接管队列总览 | 全只读 + 审批转人工升级 |

登录页：左侧深色品牌区（声波 hero 动效 + "Compliance-first Voice Agent" 标语 + 工信部合规承诺微文案），右侧表单；登录后 stagger 进场。顶栏角色切换芯片，切换即时改写可见模块与按钮可用态。

## ⑤ 核心模块详述（职责 + 关键交互 + mock 数据轮廓 + ECharts）

### M1 · 实时通话监控墙 ★旗舰（详见 ⑥）
在呼/已接/转化秒级大屏 + 坐席卡片墙 + 声波 + 流式转写 + 实时漏斗。图表：**实时接通率折线（draw-in，30s 滚动窗）**。

### M2 · 外呼任务/活动调度台
- **职责**：建活动 → 导名单 → 设节奏/并发/时段/重拨策略 → 起停。
- **交互**：名单 CSV 拖拽导入（mock 解析 + 字段映射 + 脱敏校验 + 重复/黑名单/勿扰命中预检）；**节奏策略卡**（并发上限滑块、呼叫间隔、勿扰时段 21:00–09:00 可视化时间带、单号每日触达上限）；活动卡片状态机（草稿/审核中/进行中/暂停/完成）。发起前强制过合规三灯。
- **mock 数据**：6 个活动（信用卡激活回访 / 逾期 M1 提醒 / 理财到期回访 / NPS 满意度回访 / 额度提升告知 / 还款日提醒），各含名单量、已呼/接通/转化、并发、合规校验结果。
- **图表**：**活动并发-接通率双轴时段柱线图**（24h 时段）。

### M3 · 坐席协同 · 转人工队列
- **职责**：大额/敏感/客户要求时 AI 转人工，队列调度。
- **交互**：转人工触发规则可视化（金额阈值 / 投诉敏感词 / 三次未识别意图）；队列卡片含等待时长、上下文摘要、AI 已收集字段、一键"接管"模拟；坐席忙闲泳道。引用**华帝案例**作 benchmark 标注：转人工率降 37%、ASR 93%、满意度 >90%。
- **图表**：**转人工原因构成环形** + 人工 vs AI 处理时长对比条。

### M4 · 话术流编排器（复用 Agent 流程画布）
- **职责**：可视化对话树搭建——开场 → 意图识别 → LLM 节点 → 分支话术 → 结束/转人工。
- **交互**：节点画布（拖拽连线，节点类型：开场白/LLM 理解/条件分支/TTS 播报/采集字段/转人工/挂机）；**可打断/插话处理**配置（barge-in 灵敏度、客户抢话时打断 TTS、静默兜底重述）；右侧节点属性面板（prompt、可选意图、超时与重试）；顶部"模拟运行"走查一条路径并高亮节点。
- **mock 数据**：信用卡激活回访完整树（含"已激活/未激活/拒接回访/转人工"4 分支）。
- **图表**：**话术路径 Sankey/桑基图**（各分支走向占比）。

### M5 · 语音/音色配置（TTS 试听）
- **职责**：选音色、调情感与语速、试听。
- **交互**：音色卡片网格（沉稳女声/亲和男声/标准客服音…），每卡带**波形预览 + 播放按钮**（mock 音频或 Web Audio 合成波形动画）；情感滑块（亲和度/正式度/语速/停顿）；对比 A/B 两个音色并排试听；标注 TTS 选型参照 **ElevenLabs**（情感语音标杆）与国内沃丰/得助引擎。
- **图表**：**音色试听完播率 / 客户挂断率小型对比条**。

### M6 · 通话记录 · 转写回放（复用客服/质检转写组件）
- **职责**：ASR 文本 + 情绪/意图标注 + 录音回放，合规留痕入口。
- **交互**：左列通话列表（可筛活动/结果/是否命中敏感词），中列**双气泡转写时间轴**（AI 翡翠 / 客户灰，每句带情绪 chip + 意图 tag + 静默/抢话标记），顶部**声波进度条 + 播放控制**，转写句点击高亮对应波形位置；右列"本通摘要 + 采集字段 + 合规判定 + 转人工与否"。**录音留痕**徽章（保存期限/访问日志/不可下载提示）。
- **mock 数据**：3 条完整转写（一条命中"投诉"敏感词触发转人工，一条正常激活成功，一条无人接听）。
- **图表**：**单通情绪曲线**（时间轴上的客户情绪起伏折线）。

### M7 · 线索评分与转化漏斗（复用评分卡）
- **职责**：通话结果 → 线索分级 → 漏斗诊断。
- **交互**：评分维度卡（接通/有效沟通/意向表达/字段完整/无投诉），权重可调即时重算；线索表（评分、等级 A/B/C、建议动作）。
- **图表**：**转化漏斗**（呼出→接通→有效通话→意向→转化/回收）+ **线索评分分布直方图**。

### M8 · 数据回流 · 话术 A/B
- **职责**：把通话数据回流，驱动话术迭代。
- **交互**：A/B 两版话术并排（开场白/异议处理差异 diff 高亮）；显著性判定徽章（mock 置信度）；"采纳获胜版"模拟。
- **图表**：**A/B 接通-意向-转化分组柱** + **多版本话术转化趋势多线**。

### M9 · 合规与质检中心 ★金融差异化核心
- **职责**：呼应工信部 1500 家处罚痛点——把"不被罚、不封号、可追溯"做成产品。
- **交互**：① **频控仪表**（单客户日/周触达上限、勿扰时段命中拦截数、剩余配额环形）；② **敏感词/骚扰词库**（命中即标红 + 触发动作：警告/转人工/挂断/封活动）；③ **外呼资质与外显号台账**（线路资质有效期、外显号报备状态、号码健康/封号风险评分）；④ **录音留痕审计**（每通保存期限、访问日志、合规判定流水）；⑤ 违规自动拦截事件流（实时滚动）。质检官可一键"封停活动"。
- **mock 数据**：本月频控拦截 1,284 次、勿扰时段拦截 312 次、敏感词命中 47 次、号码风险预警 3 条、资质 1 条临期。
- **图表**：**合规风险雷达**（频控/敏感词/资质/号码健康/投诉率五维）+ **违规拦截趋势堆叠面积** + **号码健康散点（呼叫量×封号风险）**。

### M10 · 号码/线路 · 外显号资质管理
- **职责**：号码池、线路供应商、外显号报备、健康度。
- **交互**：号码池表（号码、归属地、今日呼量、接通率、风险分、状态）；线路供应商资质卡（牌照/有效期/合规认证，标注参照 **Retell AI** 的可靠性与合规认证定位）；一键停用高风险号码。
- **图表**：**号码池利用率热力日历** + 供应商接通率对比条。

## ⑥ 旗舰演示页 — 实时通话监控墙（最炸的一屏）

**目标**：一屏内做出"AI 正在替我打几十通电话"的临场作战感，张力压过财务/风控大盘。

**布局（Dark · 翡翠 accent）**
- **顶部 KPI 带**：在呼中(实时 tick) · 今日已接通 · 实时接通率 · 转化数 · 合规拦截数——全 count-up + 秒级跳动，接通率 chip 颜色随阈值变。
- **主区左 2/3 · 坐席卡片墙**：12–20 张 AI 坐席卡网格，每卡：坐席编号 + 当前客户(脱敏) + 活动名 + **状态(拨号中/振铃/通话中/小结)** + **实时声波条**（通话中=翡翠流动波形，静音=灰平线）+ 通话计时。卡片状态用 GSAP/timeline 驱动：接通瞬间脉冲一下 + 边框翡翠提亮，挂断淡出换下一通。营造"墙在呼吸"。
- **主区右 1/3 上 · 实时转写流**：选中某张坐席卡 → 流式打字机式吐出该通双气泡转写，AI 句翡翠、客户句灰，新句从底部上浮 + stagger，敏感词命中行琥珀高亮并触发右侧告警。
- **右 1/3 下 · 实时转化漏斗**：呼出→接通→有效→意向→转化，随秒级数据回填动画。
- **底部窄条 · 实时事件流**：滚动日志（"#A07 接通 信用卡激活回访 · 02:14""#B12 触发敏感词[投诉] → 转人工""频控拦截 北京 138****"）。

**动效要点（GSAP + 缓动，呼应 DESIGN.md §5）**：声波用 SVG path 或 canvas 逐帧；卡片状态切换 timeline；转写打字机节流；KPI count-up；尊重 `prefers-reduced-motion`（降级为静态波形 + 即时数值）。
**图表**：实时接通率滚动折线（30s 窗，draw-in）+ 转化漏斗。
**临场感而不 spammy**：节奏克制、配色冷静、文案全为合规回访口吻，右上合规三灯常亮提醒"一切在规内运行"。

## ⑦ 差异化 + 反 slop 要点

- **差异化护城河 = 合规**：M9 合规质检中心 + 全站合规三灯 + 录音留痕，是对工信部 >1500 家处罚、>40% 产品资质缺失痛点的正面回应——这是金融客户买单的真正理由，也是与通用 voice agent demo 的分水岭。
- **临场感差异化**：旗舰监控墙的声波 + 流式转写 + 呼吸式卡片墙，是矩阵里独一份的"动态作战"观感。
- **复用而非重造**：转写双气泡时间轴、情绪/意图 chip 直接复用**客服/质检中台**的转写组件；话术编排画布复用 **Agent 流程画布**；监控大屏骨架复用风控/LLMOps 的**实时大屏骨架**；评分卡复用质检/风控的**评分卡组件**（见 00 文档 §5 复用矩阵）。
- **反 AI-slop（在 DESIGN.md §8 通则之上的本 demo 专项）**：
  - [ ] 声波/脉冲动效**有缓动有节奏**，不是生硬闪烁霓虹；接通脉冲 ≤1 次不闪瞎。
  - [ ] accent 锁翡翠，金仅用于资质/认证徽章；**绝无电销红橙**与紫发光。
  - [ ] 所有话术、客户名、活动名为**真实消金回访语料**（脱敏），无 lorem ipsum / "Acme"。
  - [ ] ≥7 张真 ECharts 图 + 声波可视化为真 SVG/canvas，**禁假 div 进度条冒充图表/波形**。
  - [ ] 数字全 tabular-nums，秒级 tick 不抖动跳行；4px 网格；UI chrome 无 emoji（lucide）。
  - [ ] 文案克制专业，无"赋能/无缝/一站式/智能营销轰炸"。

**图表清单（≥7 张真 ECharts + 声波）**：① 实时接通率折线 ② 活动并发-接通率双轴时段柱线 ③ 转人工原因环形 ④ 话术路径桑基 ⑤ 单通情绪曲线 ⑥ 转化漏斗 ⑦ 线索评分分布直方 ⑧ A/B 分组柱 ⑨ 合规风险雷达 ⑩ 违规拦截趋势堆叠面积 ⑪ 号码健康散点 ⑫ 号码池利用率热力日历。声波可视化贯穿 M1/M5/M6（非图表，独立 SVG/canvas）。

## ⑧ 5 分钟演示流（讲故事顺序）

1. **登录**（10s）：声波 hero + "Compliance-first" 标语，以"外呼运营"角色进入。
2. **旗舰监控墙**（90s）：坐席卡片墙呼吸、接通脉冲、点开一张卡看流式转写、敏感词命中飘琥珀告警、转化漏斗回填——"AI 此刻正在打 18 通电话"。
3. **任务调度台**（45s）：导名单 → 黑名单/勿扰预检 → 拖节奏滑块 → 合规三灯过审 → 起活动。
4. **话术编排器**（45s）：展开信用卡激活回访对话树，模拟运行高亮路径，演示 barge-in 打断配置。
5. **合规质检中心**（60s · 杀手锏）：频控拦截 1,284 次、敏感词命中流、号码封号风险预警、录音留痕审计——切"合规官"角色一键封停违规活动；点名工信部 1500 家处罚背景。
6. **数据回流 A/B**（30s）：获胜话术转化更高，一键采纳。
7. **切 Light 主题 + 切角色**（20s）：白班质检视角，证明双主题与 RBAC。
