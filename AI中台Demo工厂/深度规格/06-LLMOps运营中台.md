## ① 一句话定位 + 行业锚定

**「LLM / Agent 应用上线后的运营操作系统」**——把分散在日志、表格、人工抽查里的 prompt 管理 + tracing/observability + eval + 成本监控四件事，收进一个 Datadog 级的工程仪表盘。

- **行业锚定**：AI-native / 通用 SaaS。对 Hans 而言这是 **「App Factory 的运营仪表盘」**——他的每个 AI 应用都接这套中台来观测、评测、控成本。
- **市场动能（为何此刻立项）**：ClickHouse 2026-01 收购 Langfuse 并同期融 $400M；Arize 拿下 $70M C 轮（AI observability 史上最大单笔）；LangChain（LangSmith）估值 $1.25B。推理花费已占企业 AI 预算 **85%**（a16z），且 **60% 的 AI 项目超预算 30–50%**——"观测 + 控成本"从加分项变刚需。
- **技术事实锚**：OpenTelemetry GenAI 语义约定已成事实标准；Langfuse 开源 MIT、每月 600 万+ SDK 安装。本 demo 的埋点字段、trace 结构均贴这套约定，体现"接得上真实生态"。

## ② 视觉签名 / point of view

**「Datadog / Linear 级工程仪表盘」**——这是 `minimalist-ui` 最出彩的题材，也是本 demo 的护城河：高密度而不杂乱、克制到只剩信息、发丝线分区、tabular 数字像示波器读数。

- **主题**：默认 **Dark「Command Graphite」**（工程师的深色作战室，长时间盯盘不刺眼）；提供 Light「Studio Porcelain」一键切。Dark 为本 demo 的"主场景"。
- **accent 适配**：本 demo 把页面主 accent 从金改为 **翡翠绿 `--emerald #34C892`**（"系统健康/在线"的工程语义），金 `--gold` 退为稀缺强调（仅用于"成本"与"被选中的实验组"）；语义色 success/warning/danger 严格用于状态徽标。**一页一 accent 锁**仍生效。
- **密度签名**：信息密度对标 Datadog——单屏可容 4–6 个图表块 + 一条 trace 列表，但靠发丝线 + 11px 大写灰分区标题 + 充足行高维持呼吸感。**绝不**用大圆角卡片堆砌的"消费级 SaaS"观感。
- **数字即主角**：延迟（ms / p95）、token、$、评分均 `tabular-nums` + Geist Mono，小数位对齐；趋势用细线 + 渐变面积，不用粗柱。
- **一句 Design Read**：克制的深色仪表盘，绿是"活着"，金是"花钱"，红是"出事了"——颜色只为状态服务，不为装饰。

## ⑤ 核心模块详述（职责 + 关键交互 + mock 数据轮廓 + ECharts）

### 5.1 调用链 Tracing（瀑布图）
- **职责**：一条请求从 `用户输入 → retrieve → prompt 组装 → LLM 调用 → tool call → completion` 的全链路展开，定位"慢/贵/错在哪一跳"。
- **关键交互**：左列 trace 列表（可按 latency / cost / 错误 / 模型 筛排）；点开右侧**瀑布图**——每个 span 一行横条，宽度=耗时、底色=类型（retrieve/llm/tool/parse）、悬停看 token & cost & 状态；span 点开看该跳的 prompt/completion 原文与 OTel 属性（`gen_ai.request.model`、`gen_ai.usage.input_tokens` 等）。一键「⊕ 加入测试集」把该 trace 的输入沉淀为 eval 用例。
- **mock 数据**：~1,200 条 trace；字段 `trace_id / app / model(gpt-4o/claude/Qwen) / latency_ms / tokens_in/out / cost_usd / status / spans[]`。
- **ECharts ①**：**span 瀑布图**（`custom` series 或 `bar` + `stack` 占位偏移实现）——X 轴时间(ms)，Y 轴 span 名，横条按类型上色，关键路径加金色描边。
- **ECharts ②**：trace 详情页顶部 **latency 分布直方图**（本 app 近 1h，叠加 p50/p95/p99 标线）。

### 5.2 在线监控大盘（实时骨架）
- **职责**：上线后的脉搏——QPS、p95 延迟、错误率、缓存命中率、并发，秒级刷新感（mock 用定时器制造数据流动）。
- **复用**：直接套**实时监控大屏骨架**（复用矩阵 ✓），KPI count-up + 图表 draw-in。
- **ECharts ③**：**QPS / 错误率双轴时序线**（近 6h，滚动窗口，错误率超阈值区间染红）。
- **ECharts ④**：**缓存命中率 + token 吞吐 堆叠面积**（命中/未命中分层，体现省钱杠杆）。

### 5.3 Eval 数据集 + 评分看板
- **职责**：离线评测闭环——数据集（线上 trace 沉淀 + 人工构造）→ 跑评测（LLM-as-judge 多维度 + 规则）→ 看板对比版本/模型回归。
- **关键交互**：数据集列表（用例数、来源、最近跑分）；选数据集 × 选 prompt 版本/模型 → "运行评测"（mock 进度）→ 出**评分矩阵**：行=用例或版本、列=评测维度（相关性/忠实度/有害性/格式合规/简洁度），单元格=得分热力。支持 v3 vs v4 **回归对比视图**（标红下降项）。
- **mock 数据**：5 个数据集（客服 QA 480 例、合同抽取 220 例…）；judge = `gpt-4o-as-judge`；维度分 0–1。
- **ECharts ⑤**：**评分热力矩阵 heatmap**（版本 × 维度，绿=高分金/红=回归，本 demo 标志性视觉）。
- **ECharts ⑥**：**版本评分雷达对比**（v3 vs v4 五维，直观看"哪一维退化")。

### 5.4 人工标注队列
- **职责**：judge 拿不准 / 低置信 / 抽样的样本进人工队列，标注员打分给标签，回流数据集做"黄金集"。
- **关键交互**：队列列表（待标/我的/已仲裁）+ 标注台（左 trace 上下文、右评分表单 + 标签 + 备注，快捷键 1–5 打分、J/K 翻条）；分歧样本进**仲裁**（双标对比）。
- **mock 数据**：待标 137、今日已标 64、标注者间一致性 κ=0.81。
- **ECharts ⑦**：**标注吞吐 & 一致性 时序**（日产量柱 + κ 一致性线，双轴）。

### 5.5 Prompt 版本库 + diff + 回滚
- **职责**：prompt 即代码——版本树、语义化标签、逐版 diff、灰度比例、一键回滚到稳定版。
- **关键交互**：左版本树（v1…v4，标 `prod` / `canary 20%` / `archived`）；选两版看**并排 diff**（红删绿增，高亮改动 token）；每版挂"上线后指标卡"（评分/成本/错误率），让回滚有据；`回滚` 按钮 → Owner 审批弹层 → 灰度切流条动画。
- **mock 数据**：当前 `prod=v3`、`canary=v4(20%)`；v4 diff = 新增 few-shot + 收紧输出格式。
- **ECharts ⑧**：**版本上线后指标趋势叠层**（评分 + 成本/千次调用 双线，按 v 切换段着色，回归点打 markPoint）。

### 5.6 A-B 实验 & Playground
- **职责**：上线前在线对照 + 实时试跑。
- **关键交互**：实验列表（A=v3 / B=v4，流量 50/50，转化/评分/成本三指标 + 显著性 mock）；Playground 双栏同输入跑 A/B，并排看输出 + token/延迟/cost 角标。
- **ECharts ⑨**：**A/B 累计指标对比柱**（评分/成本/p95 三组分组柱，B 优项染绿、劣项染红）。

### 5.7 成本仪表盘（按模型/项目/用户/时间拆）
- **职责**：把"推理花费占 85% 预算"这件事变成可拆解、可归因、可预警的面板。
- **关键交互**：维度切换 Tab（模型 / 项目 / 团队 / 用户）；预算进度（用量 vs 预算，超 80% 黄、超 100% 红）；下钻"某项目→某 prompt 版本→某模型"的成本构成。
- **mock 数据**：MTD $42,180 / 预算 $50,000（84%）；gpt-4o 占 58%、claude 24%、Qwen 18%。
- **ECharts ⑩**：**按模型成本堆叠面积（30 天）** + **预算燃尽线**（实际 vs 理想匀速）。
- **ECharts ⑪**：**成本构成旭日/树图**（项目→版本→模型三层下钻）。

### 5.8 告警中心
- **职责**：质量回归、输出漂移（分布偏移）、成本超限三类规则，触发后挂到总览红条 + 此处时间线。
- **关键交互**：规则列表（条件 + 渠道）+ 告警时间线（触发→定位→处置链路，可一键跳 trace / diff）。
- **mock 数据**：当前 1 条 active 告警 = "客服 QA · 忠实度评分较基线下降 11%（v4 canary）"。

> 计 **11 个真 ECharts 图表**（瀑布 / 直方 / 双轴时序 / 堆叠面积 / 热力矩阵 / 雷达 / 双轴吞吐 / 指标叠层 / 分组柱 / 燃尽 / 旭日），全部走项目统一 ECharts theme（透明底、发丝线、tabular、draw-in），无一处假 div 进度条。

## ⑥ 旗舰演示页 ·「运营总览大盘」

一屏讲清"系统是否健康 + 钱花在哪 + 质量有没有退 + 现在哪里着火"，并埋下旗舰故事线的入口。

布局（Dark · 12 栅格，发丝线分区）：
1. **顶部 KPI 条**（4 张 StatCard，count-up）：在线 QPS `312`、p95 延迟 `1,840ms`、今日成本 `$1,640`（金）、近 24h 平均评分 `0.86`，各带环比 TrendChip。
2. **左主区 · trace 瀑布缩略**（ECharts ①）：最近一条慢/异常 trace 的瀑布，点击进 Tracing 全详情。
3. **右上 · 成本仪表盘（按模型拆分）**（ECharts ⑩ 紧凑版堆叠面积 + 预算进度条）——金色，唯一"花钱"色。
4. **右中 · Eval 评分矩阵**（ECharts ⑤ 缩略 heatmap）：最近一次评测 v3 vs v4，**v4 的"忠实度"列泛红**——故事钩子。
5. **顶部右侧红条 · 告警**：`⚠ 客服 QA 忠实度 -11%（v4 canary）` —— 点它直接进入下面的故事线。
6. **底部 · 在线监控双轴时序**（ECharts ③）：QPS/错误率脉搏，制造"活着"的动态感。

**🎯 旗舰故事线（5 步，一镜到底，本 demo 的灵魂）：**
> **发现 prompt 回归 → diff → 回滚 → 成本下降**
1. **发现**：总览红条告警"v4 canary 忠实度评分较基线 −11%"，旁边评分矩阵该列泛红。
2. **定位**：点告警 → 跳 Eval 看板，v3/v4 雷达对比一眼看到"忠实度"维度塌陷；点一条失败用例 → 跳到对应 trace 瀑布，看到 v4 的 prompt 把一段约束 few-shot 删了。
3. **diff**：跳 Prompt 版本库，v3 ↔ v4 并排 diff 红绿高亮，坐实"v4 删了忠实度约束 + 为省 token 砍了示例"。
4. **回滚**：点「回滚到 v3」→ Owner 审批弹层 → 灰度切流条从 `v4 20%` 动画滑回 `v3 100%`，canary 下线。
5. **成本下降 + 质量回升**：回到总览，监控时序里错误率回落、评分矩阵该列复绿；**且成本曲线下探**（v4 虽省单次 token，但触发更多重试/长输出，实际成本反升——回滚后成本/千次调用从 `$0.92 → $0.74`）。一句收尾标注体现洞察：**"省 token ≠ 省钱，错误的 prompt 会用重试把钱赔回去。"**

这条线把四个模块（告警→eval→trace→prompt）串成一个真实运营事件，是"懂 Agent 运营"最有说服力的证据。

## ⑦ 差异化 + 反 slop 要点

**差异化（vs 市面 LLMOps 截图/竞品）：**
- **不止"展示功能"，而是演完一个运营事件**：发现回归 → diff → 回滚 → 成本下降的完整故事线，是绝大多数同类 demo 没有的"闭环叙事"。
- **成本与质量的反直觉洞察**（省 token ≠ 省钱），体现判断力而非堆图表。
- **贴真实生态**：埋点字段走 OpenTelemetry GenAI 语义约定，模型/术语用真实生态（LangSmith/Langfuse/Arize/Phoenix/W&B Weave/字节 Coze Loop 的能力面均被覆盖），不是凭空造词。
- **trace 瀑布 + 评分热力矩阵**两个高难可视化做成真 ECharts，是 minimalist-ui 在"工程仪表盘"题材的炫技点。

**反 AI-slop 自检（在 DESIGN.md §8 红线之上，本 demo 补充）：**
- [ ] 主 accent 锁翡翠绿（健康），金仅给"成本/选中实验"，红仅给告警/回归——**颜色只服务状态**，无装饰性渐变、无 AI 紫发光。
- [ ] 所有延迟/token/$/评分一律 tabular-nums + Mono，小数位对齐如示波器。
- [ ] 11 个图表全真 ECharts（瀑布/热力矩阵尤甚），零假 div 条。
- [ ] 数据真实可信：模型名、token 量级、$ 量级、评分 0–1、κ 一致性均贴行业真实区间，无 lorem ipsum / "Acme"。
- [ ] 文案工程化具体（"p95 延迟""忠实度回归""灰度 20%""成本/千次调用"），无"赋能/无缝/一站式"。
- [ ] UI chrome 全 lucide 图标（Activity / GitBranch / FlaskConical / DollarSign / AlertTriangle），strokeWidth 1.75，无 emoji。
