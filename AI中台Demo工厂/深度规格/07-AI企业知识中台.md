## ① 一句话定位 + 行业锚定

**面向专业服务 / 通用大型企业的 AI 企业知识中台（Work AI / 企业搜索）**：把散落在 100+ SaaS 里的企业知识统一索引、按权限检索、用 RAG 给出**可溯源回原文**的个性化答案，并用 Agent 把"问到"升级为"做到"。

- **行业锚定**：专业服务 / 通用大型企业；副标可切**金融投研知识库**（研报、尽调、合规备忘录、内部沿革）。
- **标杆**：Glean 2025-12 达 **$200M ARR**（9 个月翻倍）、估值 **$7.2 亿**；Glean Agents 年化 **1 亿+ actions** 冲 10 亿；定价 **$100K–500K/年**、聚焦 **500+ 员工**企业。竞品：Microsoft 365 Copilot、Moveworks、Amazon Q、Guru。
- **中国对照**：腾讯 ima、飞书知识问答、钉钉 KAG；**85% 企业 AI 应用以 RAG 为核心架构**。

## ② 视觉签名 / point of view

**"权限感知 + 可溯源" 的克制企业知识层（Editorial Knowledge Layer）。**

纯搜索框 UI 极易平庸——本 demo 的护城河不在"搜"，而在两点的可视化表达：**① 每个答案都带溯源卡片（标来源文档/作者/更新时间/置信度）；② 每次检索都按当前用户权限严格过滤（界面显式展示"已为你过滤 N 条无权结果"）。** 审美靠**知识图谱可视化 + 治理控制台**拉开，而非堆搜索结果。

- 视觉气质：编辑式精致、克制留白、大面积高级中性灰 + 一处恰到好处的光；引用 `DESIGN.md` §1 mood vocabulary（Quiet Command / Editorial Refinement / Data-Forward）。
- **主题**：默认 **Anthropic Warm Ivory**（暖瓷骨色，最贴"知识/文献/编辑"气质），另备 Dark「Command Graphite」。accent 一页一锁：知识层用**靛蓝 `#4C6FE0`（trust/索引感）** 作 hero，溯源/权限态用 success/warning 语义色，不与 accent 抢。
- 溯源是第一视觉语言：答案里的每个事实句尾带可点的角标 `[1] [2]`，hover 浮出溯源卡片（缩略图 + 文档名 + 路径 + 权限徽标 + "跳到原文第 X 段"）。
- 反"AI 搜索花哨"：无打字机假流式滥用、无满屏卡片瀑布、无紫色发光；列表呼吸感强、信息密度克制。

## ③ 角色 RBAC（4 角色 × 权限矩阵 + 登录页 + 角色切换）

沿用 `AuthContext` 模式（见 §3）。**权限直接驱动检索结果与图谱可见性**，是本 demo 的差异化核心，不能只是装饰。

| 角色 | 典型人 | 可见数据域 | 关键权限 |
|---|---|---|---|
| **员工 Member** | 顾问/分析师 | 本人 + 公开 + 所属项目 | 搜索、问答（仅授权源）、用现成 Agent、看本人使用分析 |
| **知识管理员 Knowledge Admin** | 知识/情报负责人 | 全公开域 + 内容质量域 | 内容生成/Canvas、主动情报策展、连接器健康监控、答案纠错回流 |
| **平台管理员 Platform Admin** | IT/平台 | 全租户（除受限标密） | 连接器接入、Agent Builder 发布、权限/治理控制台、ROI 仪表盘 |
| **合规/审计 Compliance** | 法务/合规 | 全审计日志（只读） | 审计检索、敏感访问追溯、DLP 策略查看、导出合规报告 |

- **登录页**：Ivory 主题品牌动效（标题分词淡入上浮 + 索引脉冲微动），4 张角色卡一键切换体验。
- 角色切换时，**同一条查询的结果数与图谱节点实时收缩/展开**（演示"权限感知"最有冲击力的一招）。

## ⑤ 核心模块详述（职责 + 关键交互 + mock 数据轮廓 + ECharts）

> 参考架构（Glean 式，贯穿全模块）：100+ 连接器 → 实时索引+embedding（事件流增量）→ 企业知识图谱（人/文档/项目本体 + 个人图谱）→ 混合检索（向量+关键词，**权限感知严格过滤**）→ RAG 生成个性化答案（**可溯源回原文**）→ Agent 编排 → 治理层（细粒度访问控制 / 审计）。

### 5.1 统一搜索 + AI 答案（旗舰）
- **职责**：一个框，语义+关键词混合检索，权限感知过滤；上方默认给 AI 答案，下方排传统结果。
- **交互**：输入即出 ⌘K 式建议（人/文档/主题分组）；结果按"相关度 / 时间 / 来源"切；**显式横幅"已按你的权限过滤 8 条受限结果"**；每条结果带来源徽标 + 权限锁标 + 更新时间。
- **mock 数据**：~40 条结果，覆盖研报/合同/Slack 讨论/Confluence/工单/会议纪要；每条 {标题, 源, 作者, 更新时间, 片段高亮, 权限级, 相关度}。
- **图表**：来源分布**环形**（按 SaaS 来源占比）。

### 5.2 AI 助手对话（带引用溯源卡片）
- **职责**：多轮 RAG 对话，答案逐句可溯源；支持"换个角度/更详细/给我出处清单/导出"。
- **交互**：答案句末角标 `[1][2]`→ hover 浮**溯源卡片**（缩略图+文档名+路径+权限徽标+置信度+"跳到原文第 X 段"）；底部"3 个来源 · 100% 在你的权限内"绿色信任条；可对答案点👎触发"纠错回流"（送知识管理员）。
- **mock 数据**：3–4 段预设对话（如"我们去年给某金融客户的尽调方法论是什么？"），每段 2–4 个溯源。
- **图表**：答案**置信度仪表**（gauge）+ 引用来源时间线 sparkline。

### 5.3 知识图谱可视化（人/文档/主题关系，**复用风控关系图谱组件**）
- **职责**：把企业知识本体可视化——节点=人/文档/项目/主题，边=作者/引用/参与/相关；个人图谱高亮"与我相关"。
- **交互**：力导向布局，**点节点联动右栏详情**（该专家的高产领域 / 该文档的引用链）；按节点类型/部门/权限筛选；权限不可见节点显示为灰锁占位（体现"图谱也权限感知"）。
- **mock 数据**：~60 节点 / ~120 边，4 类节点配色；含 3 位"领域专家"高中心度节点。
- **图表（核心）**：ECharts **`type:'graph'` 力导向知识图谱**（与风控 demo 同组件，换本体数据与配色）。

### 5.4 Agent Builder（无代码搭 agent）
- **职责**：拖拽式编排多步 Agent / 工作流自动化（呼应 Glean Agents 年化 1 亿+ actions）。
- **交互**：左工具箱（检索/读文档/调连接器/生成/审批/通知）→ 中画布连线（**复用 Agent 流程画布**，见 §5）→ 右配置；顶部"试运行"走一遍并显示每步耗时/调用源；可发布为团队可用 Agent。
- **mock 数据**：2 个预置模板（"竞品情报日报 Agent""新员工 onboarding 答疑 Agent"）+ 空白起步。
- **图表**：Agent 月度执行量**柱状** + 各 Agent actions 占比。

### 5.5 连接器管理面板（100+ SaaS）
- **职责**：接入/监控企业数据源，实时索引 + 增量事件流状态。
- **交互**：连接器卡网格（已连/可连/异常三态），每张显示已索引文档数、最近同步、增量延迟、权限映射状态；点开看索引健康曲线 + 重新授权。
- **mock 数据**：~24 个连接器（Slack/Confluence/Jira/Google Drive/SharePoint/Salesforce/Notion/Box/GitHub/Zendesk…），文档量级真实（如 Confluence 18.2 万文档）。
- **图表**：索引覆盖**进度堆叠条** + 近 30 天增量同步**面积线**。

### 5.6 内容生成 / Canvas 协作
- **职责**：基于"在你权限内的知识"起草文档（如客户提案、研报摘要），可溯源、可协作。
- **交互**：左 prompt + 引用源勾选，右 Canvas 实时成稿，每段标注引用源徽标；版本/批注。
- **图表**：本模块以编辑体验为主，图表轻量（草稿引用源构成小环形）。

### 5.7 主动情报推送（Proactive Intelligence）
- **职责**：不等用户问，主动推"与你相关"的新知识/项目动态/专家更替。
- **交互**：时间线信息流，每条带"为什么推给你"的可解释标签（你关注的项目/你的领域/你协作的人）；可一键存入个人知识夹。
- **图表**：本周情报主题**词条热度条** + 推送命中率 sparkline。

### 5.8 权限 / 治理控制台
- **职责**：细粒度访问控制 + 审计 + DLP——把"权限感知"做成可治理的后台。
- **交互**：左角色/群组树 + 右数据域权限矩阵（继承/覆盖）；审计日志表（谁在何时检索了什么、命中哪些受限源被拦）；敏感词/DLP 策略列表。
- **mock 数据**：审计日志 ~50 行（含 6 条"受限访问被拦截"红标）；权限矩阵 5 域 × 4 角色。
- **图表**：每日检索量 vs 受限拦截量**双轴柱线** + 访问热力**日历热力图**。

### 5.9 使用分析 + ROI 仪表盘
- **职责**：向买方证明价值——采用率、节省工时、答案质量、ROI。
- **交互**：顶部 KPI 卡（count-up）：周活率、人均日查询、答案采纳率、估算月省工时；可按部门/时间下钻。
- **mock 数据**：周活 82%、人均日查询 11.4、答案采纳率 76%、月省 ~3,200 工时、可溯源率 100%。
- **图表**：采用率**趋势线** + 各部门活跃**条形** + 查询主题**旭日/Treemap**。

> **ECharts 真图表清单（≥6，禁假 div 条）**：① 知识图谱 `graph`（力导向）② 答案置信度 `gauge` ③ 来源分布环形 ④ 连接器增量同步面积线 ⑤ 治理双轴柱线 + 日历热力 ⑥ ROI 采用率趋势线 ⑦ 查询主题旭日/Treemap ⑧ Agent 执行量柱状。统一套 §3 自定义 theme（透明底、发丝线、tabular、draw-in）。

## ⑦ 差异化 + 反 slop 要点

- **差异化 point of view = 权限感知 + 可溯源**：不是又一个搜索框，是"每个答案标来源、按你的权限过滤"的可信知识层。审美与说服力都押在**知识图谱可视化 + 治理控制台**两张王牌上。
- 三栏联动（搜索结果 ↔ AI 答案引用 ↔ 知识图谱节点）是别家 demo 难抄的交互记忆点。
- **反 slop（逐条过 §3 / DESIGN.md §8）**：无 AI 紫发光（hero 用靛蓝，一页一锁）；溯源卡片信息真实具体（研报名/路径/作者，无 lorem ipsum、无 "Acme Corp"，用金融投研真实业务措辞）；图谱是真 ECharts `graph` 不是装饰 SVG；数字全 tabular；UI chrome 用 lucide 无 emoji；文案禁"赋能/无缝/一站式"。
- 克制：搜索结果不堆瀑布，留白呼吸；流式答案点到为止不滥用打字机。

## ⑧ 5 分钟演示流

1. **登录（Ivory 品牌动效）** → 选「员工」角色进入。（20s）
2. **旗舰搜索页**：输入"金融客户尽调方法论"，看 AI 答案逐句溯源 + 左侧"已过滤 8 条受限" + 右图高亮联动。（60s）
3. **点引用 `[1]`** → 溯源卡片浮出 →"跳到原文第 3 段"。（30s）
4. **切到「合规」角色** → 同一查询结果收缩、图谱灰锁增多、过滤数字跳变（权限感知高光）。（40s）
5. **知识图谱全屏**：点某领域专家节点 → 右栏展开其高产领域与文档引用链。（40s）
6. **Agent Builder**：打开"竞品情报日报 Agent"，试运行走一遍多步流程显示每步调用源。（50s）
7. **治理控制台 + ROI**：审计日志里点一条"受限访问被拦截"红标；ROI 仪表盘 KPI count-up（月省 3,200 工时、可溯源率 100%）收尾。（60s）
