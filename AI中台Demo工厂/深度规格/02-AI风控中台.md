## ① 一句话定位 + 行业锚定

**风控作战室（Risk Command Center）**：把反欺诈、AML 反洗钱、信用风险、实时预警四条线收进一个**毫秒级决策 + agentic 调查**的中台——交易实时打分放行/拦截/转人工，团伙与资金链在关系图谱里现形，AML 告警由 agent 自主分诊到 SAR 报告，全链路带可解释性满足 EU AI Act 审计。

- **行业锚定**：银行 / 消费金融（信用卡盗刷、账户接管、套现团伙、可疑资金流、新客信用准入）。
- **为什么是旗舰**：金融风控是 ToB AI 里**数据密度最高、决策最硬核、视觉最有张力**的场景；Hans 的金融履历让这套 demo 不是「看着像」而是「门道对」——这是无法被通用模板复制的判断。

---

## ② 视觉签名 / Point of View

**「作战室级风险指挥感」** — 沉稳克制、精密仪器、深色为主。

- **默认 Dark「Command Graphite」为主场**（DESIGN §2.1）。风控是 7×24 盯屏场景，深色降低长时眼疲劳、让风险流的红/琥珀更跳。Light「Studio Porcelain」作合规/报表副场（审计、SAR 出具更适合亮色打印感）。
- **accent 改造（行业相关换色，DESIGN §2 允许）**：本 demo 把 hero accent 从「金」收敛为**克制金 + 风险三态语义色**——`--gold` 仍是品牌稀缺光（用于品牌/选中/关键 KPI），但风险态由 `--danger 拦截 / --warning 复核 / --success 放行` 三色统领数据。**一页一 accent 锁定仍成立**：金是品牌色，红/琥珀/绿是数据语义色，不混用为装饰。
- **气质参照**：彭博终端的信息密度 × 军事指挥中心的克制 × 瑞士仪表的刻度精确。**禁霓虹、禁玻璃涂满、禁 AI 紫**（DESIGN §8）；红色只在真实风险出现时点亮，不做背景氛围灯。
- **一行 Design Read**：Dark-dominant、DENSITY 高（盯屏台）、MOTION 克制但有「心跳感」（风险流脉冲、图谱力导布局呼吸），VARIANCE 低（指挥台要稳，不要花）。

## ③ 角色 RBAC（4 角色 × 权限矩阵 + 登录 + 角色切换，沿用 AuthContext）

| 角色 | 中文 | 可见 / 可操作 |
|---|---|---|
| `risk_analyst` | 风控分析师 | 实时监控大屏、案件工作台（处置/标注）、预警处置；不可改策略、不可出 SAR |
| `aml_officer` | 反洗钱合规官 | AML 告警队列、SAR 报告生成与提交、名单/制裁筛查、可解释性面板（审计视角）；只读监控大屏 |
| `strategy_admin` | 策略管理员 | 决策规则/策略编排器（发布/灰度/回滚）、评分卡与模型监控；不可处置个案 |
| `ciso` | 首席风险官 | 全只读 + 高管驾驶舱（损失/拦截率/误报率/合规水位），导出报表 |

- **登录页**：Dark 品牌动效（DESIGN §9 第 8 点）——风控盾形标志描边 draw-in + 背景极淡风险流粒子（克制，不喧哗）。4 个角色一键演示登录卡，进站直接带对应权限与默认落地页。
- **权限落地**：未授权模块在侧栏灰显 + tooltip「需 strategy_admin 权限」；个案处置按钮按角色禁用并给原因，体现真实合规分权。

## ⑤ 核心模块详述（职责 + 关键交互 + mock 数据轮廓 + ECharts）

> 图表统一走 DESIGN §6 自定义 theme（透明底、发丝线网格、tabular 数字、圆角柱、渐变面积、draw-in）。**禁假 div 进度条冒充图表**（DESIGN §8）。下列 **≥8 张真 ECharts**。

**1) 实时交易监控大屏**（旗舰 A，详见 ⑥）
- 职责：交易风险评分流 + 实时 KPI + 决策分布 + 地理热点。
- 交互：风险流每 1.5–2.5s 推入一条新交易（mock setInterval），按评分着色（绿放行/琥珀复核/红拦截），点行抽屉看三层决策详情；可暂停/筛风险段。
- ECharts：① **实时评分时序流**（line，最近 N 笔评分滚动）② **决策分布环形**（放行/复核/拦截占比）③ **欺诈地理热点地图**（map / scatter，省份气泡）。

**2) 案件调查工作台**（旗舰 B，详见 ⑥）
- 职责：单案件 360° — 关系图谱 + 时间轴 + 三层决策证据 + agent 调查纪要 + 处置。
- 交互：左案件列表，中 **ECharts graph 力导向关系网络**（账户/设备/IP/收款人/卡 多类型节点，边=资金/共享设备/同 IP），点节点高亮 1–2 跳邻居、拖拽重布局；右栏 agent 调查时间线（「关联 3 个账户共享设备指纹 → 命中套现团伙特征 → 建议拦截 + 生成 SAR」）。
- ECharts：④ **关系网络图（graph 力导向）** ⑤ **资金流向桑基图**（Sankey：源账户→中转→收款人，宽度=金额）。

**3) 反欺诈关系网络（团伙挖掘）**
- 职责：全局视角找团伙（社区发现着色），不限单案。
- 交互：按时间窗/金额阈值/团伙规模筛；社区用 category 着色；点团伙看该簇汇总卡（涉及账户数、累计金额、共享特征）。
- ECharts：⑥ **大规模 graph**（categories 分团伙簇 + 力导向，节点 80–150 个 mock）。

**4) 实时预警处置中心**
- 职责：把高危信号变成可处置工单（冻结/二次验证/转人工/放行）。
- 交互：预警卡流（SLA 倒计时、风险标签），一键处置 + 处置后回填反馈（真/误报）喂「反馈再训练」叙事；批量处置。
- ECharts：⑦ **处置漏斗**（预警→分诊→处置→结案）+ SLA 达成 sparkline。

**5) AML 告警队列（agentic 分诊）**
- 职责：可疑交易告警的智能排队与自动分诊——这是 2026 前沿叙事承载页。
- 交互：每条告警显示 **agent 分诊结论 + 置信度 + 建议动作**；顶部水位条「本批 312 条告警，agent 自主处置 **85%** 常规告警，**47 条**升级人工」（ComplyAdvantage 口径）；人工只看升级队列，点开看 agent 已做的核查步骤（名单比对/历史行为/资金链）。
- mock 轮廓：告警 ID、规则触发（结构化拆分/快进快出/异常对手方）、agent 状态（已自动结案/已升级/待人工）、SLA。
- ECharts：⑧ **告警处置堆叠条**（按类型 × agent自动/人工，stacked bar）。

**6) SAR 可疑交易报告生成**
- 职责：从案件一键生成可疑交易报告（SAR）草稿，合规官审改提交。
- 交互：左案件证据 → 右 SAR 表单**自动预填**（主体、可疑模式叙述、关联交易明细、建议），字段标「AI 草拟 / 人工已核」徽标；提交流转（草稿→复核→上报）。体现「agentic 把调查从天压到分钟」。

**7) 名单 / 制裁筛查**
- 职责：客户/对手方对 OFAC / EU / UN / PEP 名单的实时与批量筛查。
- 交互：单查（输入名 → 模糊匹配候选 + 相似度分 + 命中名单来源）+ 批量筛查任务表；命中走「转人工复核」联动告警队列。
- ECharts：⑨ **命中相似度分布**（histogram，演示阈值取舍）。

**8) 决策规则 / 策略编排器**
- 职责：可视化编排「规则 + ML 评分 + LLM/agentic 调查」三层决策。
- 交互：策略卡列表 + 规则编辑（IF 设备指纹异常 AND 金额>阈值 AND 评分>0.8 THEN 拦截）；**灰度发布**（10%→50%→100%）+ 版本对比 + 一键回滚；体现策略治理而非堆 if-else。
- ECharts：⑩ **策略命中量与拦截率双轴**（bar + line，发布前后对比）。

**9) 风险评分卡 + 模型表现监控**
- 职责：信用/欺诈评分卡展示 + 模型健康度（漂移、衰减、误报率）。
- 交互：评分卡分段（A–E 风险档）+ 准入建议；模型监控看 KS/AUC、PSI 漂移、误报/漏报趋势，触发再训练提示。
- ECharts：⑪ **评分分布直方图**（按好坏客户叠加）+ ⑫ **PSI 漂移折线** + KS 曲线。

**10) 模型可解释性面板（SHAP · EU AI Act）**
- 职责：对单笔决策给特征贡献度解释——合规审计的硬通货。
- 交互：选一笔拦截 → **SHAP 特征贡献条形**（设备异常 +0.32 / 夜间交易 +0.18 / 收款人首现 +0.15…）+ 自然语言解释 + 「本决策可追溯至策略 v2.3 + 模型 fraud-xgb-0612」审计指纹。顶部合规水位「EU AI Act 高风险 AI 审计就绪度 **96%**，2026-08-02 强制生效」。
- ECharts：⑬ **SHAP 贡献度条形**（正负双向）+ ⑭ **全局特征重要度**。

## ⑥ 旗舰演示页（最炸的两屏 — 灵魂所在）

**旗舰 A · 实时反欺诈监控大屏（默认落地，10 秒定生死）**
- 顶部 4 张 StatCard（count-up）：今日交易笔数、实时拦截额（金色大数）、当前风险评分均值、agent 自主处置率。
- 中央左：**实时风险评分流**——交易像心电图一样滚动推入（mock 流，1.5–2.5s/笔），高分笔触红色脉冲一下再入列；这是「心跳感」MOTION 的核心。
- 中央右：**欺诈地理热点地图**（中国省份气泡，热点城市放大脉冲）。
- 底部：决策分布环形 + 实时告警 ticker（横向滚动「卡尾 4821 账户接管已拦截 / 设备指纹突变转人工…」）。
- 体验目标：进站第一眼像坐进风控指挥室，红光只在真有风险时亮——**克制即高级**。

**旗舰 B · 案件调查工作台（关系图谱 + agentic 调查，深度定生死）**
- 三栏：左案件队列（按风险降序，红/琥珀标）｜中 **力导向团伙关系网络**（多类型节点 + 资金边，可拖拽/缩放/高亮邻居）｜右 **agent 调查时间线**（一步步推理 + 证据卡 + 「生成 SAR」CTA）。
- 中栏下方可切 **资金流向桑基图**，演示「钱从哪来、过哪几手、到谁」。
- 体验目标：让看 demo 的人理解 ——「过去人工查一周的团伙，agent 几分钟串好图、给结论、出报告草稿」。这是 2026 agentic AML 的钱景具象化。

## ⑦ 差异化 + 反 slop 要点（成熟判断 = 护城河）

- **2026 前沿叙事，不是堆功能**：
  - **Agentic AML**——告警调查从「天」压到「分钟」，agent 自主处理 **85%** 常规告警（ComplyAdvantage 口径），人工只啃升级件。对标 FIS×Anthropic 2026 金融犯罪 agentic AI（BMO / Amalgamated 试点）的产品形态。
  - **可解释性 = 合规硬通货**——SHAP 面板 + 审计指纹直指 **EU AI Act 高风险 AI**（信用评分/AML）2026-08-02 强制、违规罚至全球营收 7%。把「能解释」做成卖点而非补丁，是反 slop 的成熟判断。
- **威胁面真实**：用真数据立威——全球银行欺诈损失 2025 达 **$5794 亿**（Nasdaq Verafin）；GenAI 助推欺诈 2027 或达 **$400 亿**（Deloitte）；**deepfake 语音钓鱼 2025Q1 同比 +1600%**。这些进监控大屏的「威胁态势」卡，不进正文当口号。
- **反 slop 红线（DESIGN §8 之上额外自律）**：
  - 红色是**风险信号不是装饰**——无风险时界面是沉稳石墨，红只在真拦截时点亮，绝不做红色氛围背景。
  - 关系图谱是**真 ECharts graph 力导向**，不是贴静态图；节点可拖、邻居可高亮。
  - 金融数字全 `tabular-nums`，金额带千分位 + 币种；评分保留两位小数对齐。
  - 文案讲门道（结构化拆分 / 快进快出 / 账户接管 / PSI 漂移 / KS），无「赋能/无缝/智能化」陈词。
  - 名单/制裁用真实名单体系（OFAC / EU / UN / PEP），不杜撰。

## ⑧ 5 分钟演示流（讲给金融客户听）

1. **0:00 登录** → 选 `risk_analyst` 进站，盾形动效 + 风险流粒子，落地实时监控大屏。
2. **0:30 监控大屏** → 看风险评分流心跳滚动、地理热点脉冲、实时拦截额 count-up；指一条红色拦截笔点开抽屉看三层决策。
3. **1:30 案件工作台** → 从大屏跳一个高危案件 → 力导向关系图谱「三个账户共享设备指纹」一拖现形 → 桑基图看资金链 → 右栏 agent 调查时间线给结论。
4. **2:45 一键生成 SAR** → 点「生成 SAR」→ 报告草稿自动预填，切 `aml_officer` 角色复核提交。讲「天 → 分钟」。
5. **3:30 AML 告警队列** → 水位条「agent 自主处置 85%」，只看升级队列；点开看 agent 已做的核查步骤。
6. **4:10 可解释性面板** → SHAP 贡献条 + 审计指纹 + 「EU AI Act 就绪度 96%」；讲 2026-08-02 强制、罚 7% 营收，合规即生意。
7. **4:40 ⌘K + 主题切换** → ⌘K 冻结一张卡演示快捷操作；切 Light 主题展示报表副场；收尾。
