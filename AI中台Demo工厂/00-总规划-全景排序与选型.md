## 0. 这是什么 / 怎么用

这是 Hans 转 B 端 AI 产品的**履历 demo 矩阵**：15 个 AI 中台按"需求×成熟×上升×履历"排序，选 7 个出了 build-ready 规格（本目录 `深度规格/`），其余 8 个出一页 brief（`一页brief/`）。

**你的任务**：按本目录每份规格，逐个产出**纯前端 mock demo**（无后端），审美 **≥ 本项目已交付的车企「销售策略 AI 工作台」**。每个 demo 是独立 React 应用（建议各开独立项目目录，复用本项目脚手架）。

**铁律**：审美不达标 = 交付失败。严格套用本项目 `DESIGN.md` 的高级感关键词 + token + 反 AI-slop 红线。每个 demo 必须有**自己的视觉签名 / point of view**，绝不做无表情通用模板。

## 3. 共用设计契约（全 demo 通用 · 摘自本项目 DESIGN.md）

> 详见项目根 `DESIGN.md`。此处是跨 demo 强制统一项。

- **技术栈**：React 19 + TypeScript + Vite 6 + ECharts 5 + react-router-dom 7 + lucide-react。全 mock，无后端。`npm run build` 须绿灯。
- **三主题**（CSS-var token 同构，一键切）：Dark（Command Graphite / Aurora Glass）｜Light（Studio Porcelain / Frosted）｜Anthropic Warm Ivory。**每个 demo 至少 Dark + Light 两套**，行业相关可换 accent。
- **AppShell**：左侧 220px 侧边栏 + 顶栏（面包屑 + 全局搜索 + ⌘K 命令面板 + 主题切换 + 通知 + 用户）。
- **RBAC**：每个 demo 设 3–4 角色 × 权限矩阵 + 登录页 + 角色切换（沿用 AuthContext 模式）。
- **共用组件库**（直接从车企中台 `src/components/ui.tsx` 复用）：Card / PageHeader / StatCard（count-up）/ TrendChip / Sparkline / Badge / Segmented / ProgressBar / DataTable（可排序+空态+skeleton）/ EmptyState / SectionTitle / CommandPalette。
- **图表**：统一 ECharts 自定义 theme（透明底、发丝线网格、tabular 数字、圆角柱、渐变面积、draw-in 动画）。**禁假 div 进度条冒充图表**。
- **字体**：Latin/数字 = Geist/Outfit + tabular-nums；CJK = PingFang SC。**禁默认 Inter**。
- **动效**：进场 fadeUp + stagger；KPI count-up；图表 draw-in；微交互 hover 抬升；尊重 prefers-reduced-motion。
- **反 AI-slop 红线**（ship 前逐条过）：无 AI 紫发光/霓虹；无玻璃涂满；数字全 tabular；真实行业数据无 lorem ipsum；UI chrome 无 emoji（用 lucide）；文案具体专业无"赋能/无缝/一站式"；一页一 accent；4px 网格。
