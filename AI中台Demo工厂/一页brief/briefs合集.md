## B1 · AI 数据中台（NL2SQL + 语义层）｜行业锚定：金融/通用

- **一句话定位**：业务用自然语言问数 → 语义层/text-to-SQL 生成确定性查询 → 返回可信可治理结果。灵魂 = **"答不了报错，绝不静默返回错数"**（金融审计级可信）。
- **视觉签名**：编辑式数据工作台（问数对话 + 实时图表 + 语义层关系图），Light Studio 为主。
- **信息架构**：问数台 `/ask` · 语义层建模 `/semantic` · 查询历史 `/history` · 数据血缘 `/lineage` · 权限治理 `/governance` · 指标库 `/metrics`。
- **亮点功能**：① NL 问数框 + 多轮追问 ② 生成 SQL/查询逻辑透明可编辑 ③ **准确率/置信度标签**（已覆盖 ✓ / 超语义层范围 ⚠）④ 语义层关系图（metrics/dimensions/entities）⑤ 行列级权限 + 脱敏 ⑥ 结果一键转看板。
- **mock 数据**：金融指标（AUM、不良率、获客成本、留存）、语义层本体、查询历史。
- **关键 ECharts**：NL→自动渲染图表、语义层 graph 关系图、血缘 graph、准确率对比柱（语义层 98–100% vs text-to-SQL 90%）。
- **差异化/反 slop**：用"治理 + 置信度"做出金融可信度；禁假图表。**参照**：Snowflake Cortex Analyst（5200 周活账户）、Databricks Genie、dbt Semantic Layer 2026 基准。

## B2 · AI 内容审核中台（多模态 T&S）｜行业锚定：社交/UGC 平台

- **一句话定位**：UGC 多模态（文/图/音/视频/直播）违规识别 + 风险分级 + 人审协同 + 申诉闭环。
- **视觉签名**：实时审核态势（多模态卡片流 + 违规高亮 + 态势大屏）——**视觉冲击最强**。
- **信息架构**：实时审核队列 `/queue` · 人审工作台 `/review` · 策略配置 `/policy` · 风险态势大屏 `/situation` · 申诉复核 `/appeal` · 合成内容检测 `/synthetic` · 审核员效能 `/auditor`。
- **亮点功能**：① 多模态卡片流（风险分级配色）② 违规区域/帧高亮 ③ 一键处置 + 标注 ④ **AI 合成内容/deepfake 检测**视图 ⑤ 策略规则中心 ⑥ DSA/中国标识办法合规留痕导出。
- **mock 数据**：违规类型分布、平台来源、半年审核决定量级。
- **关键 ECharts**：风险态势大屏（类型分布/趋势/热点地图）、审核员一致性、处置漏斗、堆叠来源。
- **差异化/反 slop**：多模态 + 合成检测 + 双边合规（DSA + 标识办法）。**参照**：Hive AI（$20 亿）、ActiveFence、网易易盾；DSA 半年 90 亿+ 决定、X 罚 1.2 亿欧。

## B3 · AI 营销增长中台（CDP + 创意 + 投放 + 归因）｜行业锚定：电商/零售

- **一句话定位**：洞察 → 多模态创意生成 → 多渠道投放 → AI 归因优化 全链路营销操作系统。
- **视觉签名**：多模态创意工坊 + 投放热力 + 归因桑基（最"炫"题材之一）。
- **信息架构**：Campaign 指挥台 `/campaign` · 创意工作室 `/studio` · CDP 分群画布 `/cdp` · 投放控制台 `/ads` · 归因 ROI `/attribution` · 资产库 `/assets` · Agent 编排流 `/flow`。
- **亮点功能**：① 多模态创意生成 + 品牌合规校验 ② composable CDP 拖拽 + NL 建群 ③ 多平台预算分配 + 实时调优 ④ **多触点归因**（桑基）⑤ Agent 编排流（人审卡点）⑥ A/B 实验。
- **mock 数据**：电商大促活动、人群包、渠道 ROAS、创意素材。
- **关键 ECharts**：归因桑基、投放热力、ROAS 对比、转化漏斗、人群分布旭日。
- **差异化/反 slop**：composable CDP + 多触点归因；体现"90% 用 agent 但仅 23% 生产化"的人审成熟卡点。**参照**：Adobe GenStudio、HubSpot Breeze、Jasper；字节巨量引擎 + 豆包。

## B4 · AI 销售中台 / SDR copilot｜行业锚定：B2B SaaS

- **一句话定位**：AI 承担销售前链路（线索研究/个性化触达/资格判定）+ copilot（会议纪要/下一步/CRM 自动更新）。
- **视觉签名**：pipeline 作战看板 + **reasoning trace 可视化**（决策链）。
- **信息架构**：Pipeline 看板 `/pipeline` · 线索研究 `/research` · 触达编排 `/sequence` · Agent 构建器 `/builder` · 会议 copilot `/copilot` · 绩效漏斗 `/analytics` · 审批队列 `/approval`。
- **亮点功能**：① pipeline AI 评分 + 赢单预测 ② 多源线索富集 ③ 多渠道 sequence ④ **reasoning trace**（agent 决策链，差异化）⑤ 会议转写纪要 ⑥ CRM 自动回写 ⑦ 人审队列。
- **mock 数据**：B2B 商机、触达序列、转化、会议纪要。
- **关键 ECharts**：pipeline 漏斗、赢单预测、reasoning trace 树图、转化趋势。
- **差异化/反 slop**：**主打可信/可审计**（reasoning trace + guardrails + 人审）对冲 AI SDR 泡沫嫌疑——**别吹全自动神话**（11x 虚报客户教训）。**参照**：Agentforce（ARR $8 亿、+330%）、Clay（$31 亿）。

## B5 · Agent 编排平台｜行业锚定：通用 / 金融垂直

- **一句话定位**：把多 LLM/工具/Agent 编排成可执行、可监控的工作流（可视化画布或代码图）。
- **视觉签名**：节点画布 + 连线 + 实时数据流动画（**最炫**）—— ⚠ 必须叠**金融垂直场景 + 独特视觉签名**，避免像素级模仿 Dify/n8n。
- **信息架构**：编排画布 `/canvas` · 节点库 `/nodes` · 工具/MCP 市场 `/tools` · 调试面板 `/debug` · 多 Agent 协作视图 `/agents` · 运行历史 `/runs` · 发布 `/deploy`。
- **亮点功能**：① 拖拽节点 + 连线（DAG/图）② 实时执行可视化（节点高亮 + 数据流动画）③ 单步调试 + 变量 inspect ④ 多 Agent 消息/状态机 ⑤ MCP/工具集成 ⑥ human-in-loop 审批卡 ⑦ 一键发布 API。
- **mock 数据**：金融垂直 agent 流（如"风控调查 agent 编排""理财顾问多 agent"）避免通用化。
- **关键 ECharts**：执行时序/甘特、节点耗时、成功率、token 消耗。
- **差异化/反 slop**：垂直定位 + 独特签名破局。**参照**：a16z 2026 头号企业趋势"编排层"；Dify（$30M@$180M）、LangGraph、n8n、Coze（开源 100k+ star）。

## B6 · RAG 知识/评测中台｜行业锚定：金融投研/合规

- **一句话定位**：企业知识库"建-检-评"闭环 + 幻觉检测 + 逐句溯源 + 持续 eval。
- **视觉签名**：可信 AI 质感（评测雷达 + 答案**逐句溯源红/绿**高亮）。
- **信息架构**：文档摄取解析 `/ingest` · 知识库管理 `/kb` · 检索调试台 `/retrieval` · 评测看板 `/eval` · 幻觉检测 `/hallucination` · Eval 数据集 `/dataset` · 检索 A/B `/ab`。
- **亮点功能**：① 分块可视化 + 版面识别 ② 检索调试（query→命中 chunks + rerank 前后对比）③ 评测看板（context precision/recall、faithfulness 雷达）④ **幻觉高亮逐句标红绿 + 溯源 citation** ⑤ LLM-as-judge 批量评分 ⑥ 检索策略 A/B ⑦ 合规审计报告导出。
- **mock 数据**：金融研报/政策文档、研报问答对、溯源链路。
- **关键 ECharts**：评测雷达、检索相似度分布、幻觉率趋势、chunk 命中对比。
- **差异化/反 slop**：金融级"每个数字可溯源到原文"；企业 RAG 幻觉率**仍 >10%** = 真需求、评测侧未饱和。**参照**：RAGAS、Vectara HHEM（下载 350 万+）、Galileo、RAGFlow。

## B7 · AI 供应链/履约中台｜行业锚定：制造/零售

- **一句话定位**：需求预测 → 库存优化 → 补货采购 → 履约物流 → 风险预警 的供应链规划执行中台。
- **视觉签名**：**控制塔 + 动态物流地图 + 库存热力**（视觉冲击最强之一）。
- **信息架构**：需求预测 `/forecast` · 库存健康 `/inventory` · 补货采购 `/replenish` · 供应链控制塔 `/tower` · What-if 模拟 `/whatif` · 供应商风险 `/supplier` · 履约追踪 `/fulfillment`。
- **亮点功能**：① 多 SKU 时序预测 + 置信区间 ② 库存热力图（缺货/积压预警）③ 补货/采购建议工作流 ④ 控制塔端到端可视化 ⑤ **What-if 情景模拟** ⑥ Agent 自主补货决策 ⑦ 物流追踪地图。
- **mock 数据**：零售 SKU、门店/仓库存、物流节点、供应商。
- **关键 ECharts**：需求预测带区间、库存热力、物流地图（geo）、供应商风险雷达、成本/服务水平权衡。
- **差异化/反 slop**：agentic 自主补货 + what-if。**参照**：o9、Blue Yonder、Kinaxis；京东物流（预测准确率 70%→95%+）、联想、菜鸟。

## B8 · AI HR/招聘中台｜行业锚定：互联网/通用

- **一句话定位**：JD 生成 → 简历解析 → 匹配排序 → AI 面试 → 入职 → 人才运营/流失预测 全链路。
- **视觉签名**：人才画像卡 + 匹配雷达 + AI 面试评分可视化。
- **信息架构**：JD 生成 `/jd` · 简历库 `/resume` · 候选人匹配 `/match` · AI 面试间 `/interview` · 招聘漏斗 `/funnel` · 人才库语义搜索 `/talent` · 公平性审计 `/fairness`。
- **亮点功能**：① 智能 JD 生成 ② 简历解析 + 人才画像卡 ③ 候选人匹配雷达/排序 ④ **AI 面试间**（多模态评分可视化）⑤ 招聘漏斗转化 ⑥ Agent 自动外联/约面 ⑦ **公平性/偏见审计**（差异化 point of view）。
- **mock 数据**：岗位、候选人画像、面试评分、漏斗。
- **关键 ECharts**：匹配雷达、招聘漏斗、人才分布、面试评分热力。
- **差异化/反 slop**：人才知识图谱 + 公平性审计（避开赛道平庸）。**参照**：Mercor（$100 亿）、Eightfold、HireVue；北森、Moka、用友大易。
